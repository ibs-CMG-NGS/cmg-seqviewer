# 8. Statistical Analysis

## 8.1 Fisher's Exact Test

Perform Fisher's exact test for gene set enrichment:

1. Select **Analysis →Fisher's Exact Test**

2. Enter gene sets or upload pathway definitions

3. Results show enrichment p-values and odds ratios

## 8.2 GSEA Lite (Wilcoxon)

**GSEA Lite** is a built-in "rank-based" weighted GSEA using predefined gene sets
 (Wilcoxon-based, loaded datasets only).
 *Name distinction (A7): "GSEA prerank (gseapy)", which uses international gene sets
 (GO/KEGG) and the gseapy engine, is a separate GO/KEGG Enrichment pipeline feature (Phase 4).*

1. Select **Analysis →GSEA Lite**

2. Choose gene sets from predefined databases

3. View enrichment scores and leading-edge genes
